  <h2>PyTorch Tutorial for MATH 6373: Deep Learning and Neural Networks</h2>

  <p>I developed and led PyTorch tutorials for <strong>MATH 6373: Deep Learning and Neural Networks</strong>. The tutorials introduced students to implementing neural networks in Python using PyTorch, with hands-on notebooks covering core concepts and common deep learning architectures.</p>

  <p>Topics covered:</p>
  <ul class="topics">
    <li>Tensors</li><li>Linear regression</li><li>Feedforward networks</li><li>Classification</li>
    <li>Convolutional networks</li><li>Transfer learning</li><li>U-Net denoising</li><li>Autoencoders</li>
    <li>Data augmentation</li><li>TensorBoard</li><li>YOLOv8</li>
  </ul>
