# michelamarini.github.io

Personal academic website, built with Jekyll and hosted on GitHub Pages.

- Your details and the top menu: `_config.yml`
- News on the home page: `_data/news.yml`
- Publications: `_data/publications.yml`
- Page text: `index.md`, `research.md`, `publications.md`, `teaching.md`, `contact.md`
- Colours and fonts: `assets/css/style.css` (top of the file)
